你好，世界——我的零成本静态博客

2026 年 06 月 08 日

这大概是我第 N 次搭建博客了。WordPress、Hugo、Hexo、Notion + 中转服务……每一种都踩过一遍。这次不一样——目标很明确：零成本、零维护、纯静态。

为什么选这个方案

  • GitHub Pages 原生支持：push 即发布，不需要配 CI。
  • Markdown 写作：不绑后台编辑器，任何地方都能写。
  • 完全免费：没有域名费用、没有托管费、没有数据库。

目录结构一览

myblog/
├── index.html           # 首页
├── .nojekyll            # 告诉 GitHub 不运行 Jekyll
├── assets/
│   └── css/
│       └── style.scss   # 样式表
├── posts/
│   └── hello-world.html # 示例文章
└── README.md            # 说明文档

一点 CSS 代码

行内代码是这么写的：

.post-content {
  font-size: 1.05rem;
  line-height: 1.85;
  color: var(--color-text);
}

而一段 Python 长这样：

def greet(name):
    return f"你好，{name}！欢迎来到我的博客。"

if __name__ == "__main__":
    print(greet("世界"))

写作工具链

环节工具说明
写作VS Code / TyporaMarkdown 即时预览
图片本地截图放到仓库 images/ 目录
发布git push或 GitHub 网页直接上传

一个提醒：图片文件不要太大。每张控制在 200KB 以内，阅读体验会好很多。

下一步

  1. 修改 index.html 里的站点名和作者名。
  2. 在 posts/ 目录下新建 HTML 文件。
  3. Push 到 GitHub，刷新页面——新文章就在线了。

没有数据库备份、没有服务器宕机、没有 SSL 证书过期。这些东西 GitHub 都替你做了。

写过这么多博客工具之后，我越来越相信一个道理：工具越轻，写得越多。 你不需要一个花哨的 CMS 来开始——一段文字、一个文件、一次 git push，就够了。

如果你也在找零成本的写作方案，不妨试试这套——它已经在这里等着你了。
